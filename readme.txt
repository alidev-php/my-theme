A modern, responsive WordPress theme with RTL support.

== Description ==

AliTheme is a custom WordPress theme built from scratch with:
* Responsive design
* RTL language support
* Custom post meta with reading time
* Social sharing buttons
* Post navigation
* Beautiful header and footer

== Installation ==

1. Upload the theme folder to /wp-content/themes/
2. Activate the theme from WordPress admin
3. Create a menu and assign it to "Primary" location
